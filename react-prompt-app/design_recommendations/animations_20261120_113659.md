# Animation Suggestions

## 1. Page Transitions

Modern web applications use seamless transitions to maintain spatial context. The modern standard utilizes the native **View Transitions API** with CSS fallbacks, providing app-like fluidity without heavy JavaScript bundles.

### Shared Element Morph & Slide Transition

```html
<!-- Native View Transition Implementation -->
<nav>
  <a href="/dashboard" onclick="navigate(event, '/dashboard')">Dashboard</a>
</nav>
<main id="content">
  <h1 class="page-title">Home</h1>
</main>
```

```css
/* Page Transition Styles */
@view-transition {
  navigation: auto;
}

::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 350ms;
  animation-timing-function: cubic-bezier(0.16, 1, 0.3, 1);
}

/* Exit: Sinks and fades out slightly */
::view-transition-old(root) {
  animation-name: page-exit;
}

/* Enter: Rises from bottom with subtle scale */
::view-transition-new(root) {
  animation-name: page-enter;
}

@keyframes page-exit {
  from {
    opacity: 1;
    transform: scale(1);
  }
  to {
    opacity: 0;
    transform: scale(0.98);
  }
}

@keyframes page-enter {
  from {
    opacity: 0;
    transform: translateY(12px) scale(0.99);
  }
  to {
    opacity: 1;
    transform: translateY(0) scale(1);
  }
}
```

```javascript
// Progressive enhancement for Single Page Applications (SPAs)
function navigate(event, url) {
  event.preventDefault();

  if (!document.startViewTransition) {
    // Fallback for browsers that don't support View Transitions
    window.location.href = url;
    return;
  }

  document.startViewTransition(async () => {
    // Update the DOM dynamically here
    const response = await fetch(url);
    const html = await response.text();
    const newDoc = new DOMParser().parseFromString(html, 'text/html');
    document.querySelector('#content').replaceWith(newDoc.querySelector('#content'));
  });
}
```

## 3. Micro-Interactions

Micro-interactions bridge the gap between static interfaces and natural human sensory feedback.

### A. Magnetic Button with Dynamic Hover & Active States
A micro-interaction combining spatial lighting and physics-based feedback.

```html
<button class="interactive-btn">
  <span>Confirm Payment</span>
</button>
```

```css
.interactive-btn {
  --btn-bg: #0f172a;
  --btn-glow: rgba(99, 102, 241, 0.4);
  position: relative;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  padding: 0.875rem 1.75rem;
  font-size: 0.95rem;
  font-weight: 500;
  color: #fff;
  background-color: var(--btn-bg);
  border: 1px solid rgba(255, 255, 255, 0.1);
  border-radius: 9999px;
  cursor: pointer;
  overflow: hidden;
  transition: transform 150ms cubic-bezier(0.16, 1, 0.3, 1),
              box-shadow 150ms cubic-bezier(0.16, 1, 0.3, 1),
              background-color 200ms ease;
}

/* Spring Lift */
.interactive-btn:hover {
  transform: translateY(-2px);
  box-shadow: 0 10px 20px -10px var(--btn-glow);
}

/* Tactile Click */
.interactive-btn:active {
  transform: translateY(0.5px) scale(0.98);
  box-shadow: 0 2px 5px -2px var(--btn-glow);
}

/* Dynamic Radial Flare Overlay */
.interactive-btn::before {
  content: "";
  position: absolute;
  top: 0; left: 0; right: 0; bottom: 0;
  background: radial-gradient(circle at var(--x, 50%) var(--y, 50%), rgba(255, 255, 255, 0.15) 0%, transparent 60%);
  opacity: 0;
  transition: opacity 300ms ease;
}

.interactive-btn:hover::before {
  opacity: 1;
}
```

```javascript
// Attach spatial mouse position for illumination effect
const btn = document.querySelector('.interactive-btn');
btn.addEventListener('mousemove', (e) => {
  const rect = btn.getBoundingClientRect();
  const x = ((e.clientX - rect.left) / rect.width) * 100;
  const y = ((e.clientY - rect.top) / rect.height) * 100;
  btn.style.setProperty('--x', `${x}%`);
  btn.style.setProperty('--y', `${y}%`);
});
```

## 4. Performance Considerations

### The Compositor Pipeline: Stay on the Fast Path
Every animation runs through the browser engine: **Layout -> Paint -> Composite**.

```
❌ Layout Triggers (Costly):     width, height, top, left, margin, padding
⚠️ Paint Triggers (Moderate):   background-color, box-shadow, color
✅ Composite Only (Optimized):  transform, opacity
```

- **GPU Acceleration**: Animate **only** `transform` and `opacity`. The browser delegates these operations entirely to the GPU, avoiding expensive recalibrations.
- **`will-change` Property**: Use it sparingly. Do **not** declare it directly in CSS across dozens of elements, as it permanently consumes excessive GPU RAM.

```css
/* Avoid */
* { will-change: transform, opacity; }

/* Recommended: Add via JS prior to action, or selectively on hover */
.card-lift {
  transition: transform 250ms cubic-bezier(0.16, 1, 0.3, 1);
}
.card-lift:hover {
  will-change: transform;
  transform: translateY(-4px);
}
```

### When to Use CSS vs. JavaScript

| Criterion | CSS Animations / Transitions | JavaScript (GSAP / Motion / Web Animations API) |
| :--- | :--- | :--- |
| **Use Case** | UI micro-states, simple hovers, loading spinners, single elements. | Orchestrated sequences, drag gestures, physics/spring math, scroll synchronizations. |
| **Overhead** | 0 KB runtime overhead. Runs on the browser compositor thread. | Extra JS bundle size (e.g., 3kb - 40kb). |
| **Control** | Harder to dynamically chain, reverse, or pause mid-frame. | Total timeline control, callbacks, and dynamic variable access. |

### Accessibility (Mandatory)
Always respect user preferences for motion sensitivity:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

## 5. Ready-to-Use CSS Library

Copy and paste these presets directly into your stylesheet to create an immediate system-level feel:

```css
:root {
  /* Motion Curves (Fluid & Natural) */
  --ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
  --ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);
  --ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);
  
  /* Durations */
  --duration-fast: 150ms;
  --duration-normal: 250ms;
  --duration-slow: 400ms;
}

/* Utility Animations */
.animate-fade-in {
  animation: fadeIn var(--duration-normal) var(--ease-out-expo) forwards;
}

.animate-slide-up {
  animation: slideUp var(--duration-normal) var(--ease-out-expo) forwards;
}

.animate-pop {
  animation: popIn var(--duration-fast) var(--ease-spring) forwards;
}

/* Keyframes */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(16px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@keyframes popIn {
  0% {
    opacity: 0;
    transform: scale(0.92);
  }
  100% {
    opacity: 1;
    transform: scale(1);
  }
}

/* Transition Utilities */
.transition-smooth {
  transition: transform var(--duration-normal) var(--ease-out-expo),
              opacity var(--duration-normal) var(--ease-out-expo);
}
```
