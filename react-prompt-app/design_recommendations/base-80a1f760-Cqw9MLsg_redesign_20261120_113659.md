# base-80a1f760-Cqw9MLsg Component Redesign

Here is the complete redesign for the minified sandbox controller into a modern, production-ready React **Interactive Sandbox & Code Preview** component.

---

### 1. Current Issues

1. **Unusable Abstract Stub in Minified Form**: The snippet defines a pre-ES6 prototype-based class (`p`/`S`) with four unimplemented stub methods throwing runtime `Error("Method not implemented")`. It offers zero React integration, no hook abstractions, and cannot render any UI.
2. **Missing Lifecycle & Memory Leaks**: It manages imperative iframe references through a query selector (`iframeSelector`) rather than React `ref`s. It lacks cleanup routines for `window.addEventListener('message', ...)` and iframe teardown, causing memory leaks and dangling listeners.
3. **No State Reactivity or Error Recovery**: `this.status = "idle"` is updated mutably outside React's render loop. Errors thrown inside the iframe or during postMessage communication will crash the host context without recovery or fallback states.
4. **Security Vulnerabilities & Accessibility Deficits**: Interacting with an iframe directly via selector without strict `sandbox` permissions, origin validation, and accessible ARIA attributes (`aria-busy`, role descriptions, live status regions) exposes users to XSS and excludes screen reader users.

---

### 2. Redesign Concept

We transform the raw sandbox driver into a **Modern Interactive Sandbox Studio (`<SandboxPreview />`)**:
- **Modern Architecture**: Built as a reactive React hook (`useSandbox`) powering a rich, accessible UI component.
- **Bi-directional `postMessage` Protocol**: Type-safe event bus with structured handshake, origin verification, ping/pong health checks, and console interception.
- **Responsive Device Switcher**: Built-in viewport scaling (Desktop, Tablet, Mobile) with zoom controls.
- **Developer Experience**: Real-time console tab, status indicator (idle, compiling, ready, error), hot-reload triggers, and full-screen preview.
- **Strict Isolation**: Enforces HTML5 sandbox security boundaries (`allow-scripts`, `allow-modals`, `allow-forms`, etc.) while protecting the parent window.

// --- Types & Interfaces ---
export type SandboxStatus = "idle" | "booting" | "ready" | "error";
export type ViewportMode = "desktop" | "tablet" | "mobile";

export interface SandboxMessage<T = unknown> {
  type: string;
  payload: T;
  source: "sandbox-host" | "sandbox-client";
  timestamp: number;
}

export interface ConsoleLogEntry {
  id: string;
  level: "log" | "warn" | "error" | "info";
  message: string;
  timestamp: string;
}

export interface SandboxOptions {
  allowedOrigins?: string[];
  autoReload?: boolean;
  clearConsoleOnReload?: boolean;
  title?: string;
  sandboxFlags?: string;
}

export interface SandboxHandle {
  reload: () => void;
  dispatch: (type: string, payload: unknown) => void;
  getStatus: () => SandboxStatus;
}

export interface SandboxPreviewProps {
  /** Raw HTML or bundle source code to run in sandbox */
  code?: string;
  /** Direct src URL if loading remote trial */
  src?: string;
  options?: SandboxOptions;
  onStatusChange?: (status: SandboxStatus) => void;
  onConsoleMessage?: (log: ConsoleLogEntry) => void;
  className?: string;
}

// --- Custom Hook: useSandbox ---
function useSandbox({
  code,
  src,
  options,
  iframeRef,
}: {
  code?: string;
  src?: string;
  options?: SandboxOptions;
  iframeRef: React.RefObject<HTMLIFrameElement | null>;
}) {
  const [status, setStatus] = useState<SandboxStatus>("idle");
  const [logs, setLogs] = useState<ConsoleLogEntry[]>([]);
  const [errorMessage, setErrorMessage] = useState<string | null>(null);

  // Dispatch postMessage safely to iframe
  const dispatch = useCallback(
    (type: string, payload: unknown) => {
      const target = iframeRef.current?.contentWindow;
      if (!target) return;

      const message: SandboxMessage = {
        type,
        payload,
        source: "sandbox-host",
        timestamp: Date.now(),
      };
      target.postMessage(message, "*");
    },
    [iframeRef]
  );

  // Reload sandbox frame
  const reload = useCallback(() => {
    setStatus("booting");
    setErrorMessage(null);
    if (options?.clearConsoleOnReload) {
      setLogs([]);
    }

    if (iframeRef.current) {
      if (src) {
        iframeRef.current.src = src;
      } else if (code) {
        iframeRef.current.srcdoc = buildSandboxDoc(code);
      }
    }
  }, [src, code, options?.clearConsoleOnReload, iframeRef]);

  // Message bus listener
  useEffect(() => {
    const handleMessage = (event: MessageEvent) => {
      // Validate origins if provided
      if (
        options?.allowedOrigins &&
        options.allowedOrigins.length > 0 &&
        !options.allowedOrigins.includes(event.origin)
      ) {
        return;
      }

      const data = event.data as SandboxMessage;
      if (!data || data.source !== "sandbox-client") return;

      switch (data.type) {
        case "READY":
          setStatus("ready");
          break;
        case "CONSOLE_LOG": {
          const logPayload = data.payload as {
            level: ConsoleLogEntry["level"];
            args: string[];
          };
          const newEntry: ConsoleLogEntry = {
            id: crypto.randomUUID(),
            level: logPayload.level,
            message: logPayload.args.join(" "),
            timestamp: new Date().toLocaleTimeString(),
          };
          setLogs((prev) => [...prev.slice(-99), newEntry]);
          break;
        }
        case "ERROR":
          setStatus("error");
          setErrorMessage(String(data.payload));
          break;
        default:
          break;
      }
    };

    window.addEventListener("message", handleMessage);
    return () => window.removeEventListener("message", handleMessage);
  }, [options?.allowedOrigins]);

  // Sync source updates
  useEffect(() => {
    reload();
  }, [code, src, reload]);

  return { status, logs, errorMessage, reload, dispatch, clearLogs: () => setLogs([]) };
}

// Generate self-contained, console-intercepting HTML shell
function buildSandboxDoc(userHtml: string): string {
  return `
    <!DOCTYPE html>
    <html>
      <head>
        <meta charset="utf-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
        <style>
          body { margin: 0; font-family: system-ui, -apple-system, sans-serif; background: transparent; }
        </style>
        <script>
          (function() {
            function report(type, payload) {
              window.parent.postMessage({
                source: 'sandbox-client',
                type: type,
                payload: payload,
                timestamp: Date.now()
              }, '*');
            }

            const levels = ['log', 'warn', 'error', 'info'];
            levels.forEach(lvl => {
              const original = console[lvl];
              console[lvl] = (...args) => {
                report('CONSOLE_LOG', { level: lvl, args: args.map(a => typeof a === 'object' ? JSON.stringify(a) : String(a)) });
                original.apply(console, args);
              };
            });

            window.addEventListener('error', (e) => report('ERROR', e.message));
            window.addEventListener('unhandledrejection', (e) => report('ERROR', e.reason?.message || 'Unhandled Rejection'));
            window.addEventListener('DOMContentLoaded', () => report('READY', null));
          })();
        </script>
      </head>
      <body>${userHtml}</body>
    </html>
  `;
}

// --- Main Interactive Sandbox Component ---
export const SandboxPreview = forwardRef<SandboxHandle, SandboxPreviewProps>(
  (
    {
      code = "<h1>Live Sandbox Running</h1><p>Edit preview code to test changes live.</p>",
      src,
      options = { clearConsoleOnReload: true },
      onStatusChange,
      onConsoleMessage,
      className = "",
    },
    ref
  ) => {
    const iframeRef = useRef<HTMLIFrameElement | null>(null);
    const containerRef = useRef<HTMLDivElement | null>(null);

    const [viewport, setViewport] = useState<ViewportMode>("desktop");
    const [isConsoleOpen, setIsConsoleOpen] = useState(false);
    const [isFullscreen, setIsFullscreen] = useState(false);

    const { status, logs, errorMessage, reload, dispatch, clearLogs } =
      useSandbox({
        code,
        src,
        options,
        iframeRef,
      });

    // Expose imperative API to parents while maintaining React purity
    useImperativeHandle(ref, () => ({
      reload,
      dispatch,
      getStatus: () => status,
    }));

    useEffect(() => {
      onStatusChange?.(status);
    }, [status, onStatusChange]);

    const toggleFullscreen = () => {
      if (!containerRef.current) return;
      if (!document.fullscreenElement) {
        containerRef.current.requestFullscreen().then(() => setIsFullscreen(true));
      } else {
        document.exitFullscreen().then(() => setIsFullscreen(false));
      }
    };

    const viewportStyles = useMemo(() => {
      switch (viewport) {
        case "mobile":
          return { width: "375px", height: "667px" };
        case "tablet":
          return { width: "768px", height: "1024px" };
        case "desktop":
        default:
          return { width: "100%", height: "100%" };
      }
    }, [viewport]);

    return (
      <div
        ref={containerRef}
        className={`sandbox-root ${isFullscreen ? "is-fullscreen" : ""} ${className}`}
        aria-label="Sandbox code preview environment"
      >
        {/* Navigation / Toolbar */}
        <header className="sandbox-toolbar" role="toolbar" aria-label="Sandbox Toolbar">
          <div className="toolbar-section left">
            <span
              className={`status-badge status-${status}`}
              title={`Status: ${status}`}
              aria-live="polite"
            >
              <span className="status-dot" />
              {status.toUpperCase()}
            </span>
            <div className="sandbox-security" title="Isolated Sandbox Enabled">
              <ShieldCheck size={16} />
              <span>Isolated</span>
            </div>
          </div>

          <div className="toolbar-section center">
            <div className="viewport-switch" role="radiogroup" aria-label="Device viewports">
              <button
                type="button"
                className={`icon-button ${viewport === "desktop" ? "active" : ""}`}
                onClick={() => setViewport("desktop")}
                title="Desktop View"
                aria-pressed={viewport === "desktop"}
              >
                <Monitor size={16} />
              </button>
              <button
                type="button"
                className={`icon-button ${viewport === "tablet" ? "active" : ""}`}
                onClick={() => setViewport("tablet")}
                title="Tablet View"
                aria-pressed={viewport === "tablet"}
              >
                <Tablet size={16} />
              </button>
              <button
                type="button"
                className={`icon-button ${viewport === "mobile" ? "active" : ""}`}
                onClick={() => setViewport("mobile")}
                title="Mobile View"
                aria-pressed={viewport === "mobile"}
              >
                <Smartphone size={16} />
              </button>
            </div>
          </div>

          <div className="toolbar-section right">
            <button
              type="button"
              className={`icon-button ${isConsoleOpen ? "active" : ""}`}
              onClick={() => setIsConsoleOpen((prev) => !prev)}
              title="Toggle Console Drawer"
              aria-expanded={isConsoleOpen}
            >
              <Terminal size={16} />
              {logs.length > 0 && <span className="counter-pill">{logs.length}</span>}
            </button>
            <button
              type="button"
              className="icon-button"
              onClick={reload}
              title="Reload sandbox preview"
            >
              <RefreshCw size={16} className={status === "booting" ? "spinning" : ""} />
            </button>
            <button
              type="button"
              className="icon-button"
              onClick={toggleFullscreen}
              title={isFullscreen ? "Exit Fullscreen" : "Fullscreen"}
            >
              {isFullscreen ? <Minimize2 size={16} /> : <Maximize2 size={16} />}
            </button>
          </div>
        </header>

        {/* Viewport Frame Canvas */}
        <div className="sandbox-canvas">
          <div className="viewport-wrapper" style={viewportStyles}>
            {status === "booting" && (
              <div className="sandbox-loader-overlay">
                <div className="spinner" />
                <p>Compiling preview environment...</p>
              </div>
            )}

            {errorMessage && (
              <div className="sandbox-error-banner" role="alert">
                <AlertTriangle size={18} />
                <span>{errorMessage}</span>
              </div>
            )}

            <iframe
              ref={iframeRef}
              title={options?.title || "Interactive Sandbox Execution Frame"}
              className="sandbox-frame"
              sandbox={
                options?.sandboxFlags ||
                "allow-scripts allow-modals allow-forms allow-same-origin"
              }
              aria-busy={status === "booting"}
            />
          </div>
        </div>

        {/* Interactive Console Drawer */}
        {isConsoleOpen && (
          <aside className="sandbox-console-drawer" aria-label="Sandbox Console Output">
            <div className="console-header">
              <span className="console-title">Execution Console</span>
              <div className="console-actions">
                <button type="button" className="text-button" onClick={clearLogs}>
                  Clear
                </button>
              </div>
            </div>
            <div className="console-body" tabIndex={0}>
              {logs.length === 0 ? (
                <div className="console-empty">No console logs generated.</div>
              ) : (
                logs.map((log) => (
                  <div key={log.id} className={`console-line log-${log.level}`}>
                    <span className="log-time">{log.timestamp}</span>
                    <span className="log-level">[{log.level.toUpperCase()}]</span>
                    <span className="log-msg">{log.message}</span>
                  </div>
                ))
              )}
            </div>
          </aside>
        )}
      </div>
    );
  }
);

SandboxPreview.displayName = "SandboxPreview";

### 5. Why This is Better

| Metric | Original Code | Redesigned Component |
| :--- | :--- | :--- |
| **Component Model** | Fragmented ES5 Class (`p`), throws "Method not implemented" | Idiomatic React functional component with `useSandbox` custom hook |
| **Communication** | Stubs for `dispatch` and `listen` | Full bi-directional, type-safe `postMessage` protocol with console capturing |
| **Safety & Security** | Raw string iframe selector, unconstrained | Strict HTML5 `sandbox` attributes, domain isolation, and origin checks |
| **User Experience** | Non-existent; headless shell | Responsive device emulator (Mobile, Tablet, Desktop), Fullscreen mode, live logs |
| **Robustness** | No lifecycle cleanup or error handling | Automated event listener teardown, error boundaries, and unhandled rejection trapping |
