# Color Palette Suggestions

Here are three modern, WCAG AA compliant color palettes designed specifically for web applications, ranging from high-velocity SaaS to editorial commerce and data-dense dashboards.

---

### Palette 1: "Hyperion Indigo"
*A high-contrast, modern tech palette popular in modern SaaS, developer tools, and enterprise workflows.*

#### Colors & Hex Codes
* **Primary Colors:**
  * Base: `#4F46E5` (Vibrant Indigo)
  * Hover / Active: `#4338CA` (Deep Indigo)
* **Secondary Colors:**
  * Base: `#0284C7` (Sky Blue)
  * Subtle Tint: `#E0F2FE` (Ice Blue Tint)
* **Accent Colors:**
  * Base: `#E11D48` (Rose Red — for highlights, destructive actions, high-impact alerts)
* **Background / Neutral Colors:**
  * Canvas / Base BG: `#FFFFFF` (Pure White)
  * Surface / Secondary BG: `#F8FAFC` (Slate Canvas)
  * Card / Elevated BG: `#FFFFFF` (White)
  * Border / Dividers: `#E2E8F0` (Soft Slate)
  * Text Muted: `#64748B` (Neutral Slate — 4.6:1 on white)
  * Text Body / Headings: `#0F172A` (Ink Dark — 19:1 on white)

#### CSS Variables Code
```css
:root {
  /* Brand / Primary */
  --color-primary: #4F46E5;
  --color-primary-hover: #4338CA;
  --color-primary-subtle: #EEF2FF;

  /* Secondary */
  --color-secondary: #0284C7;
  --color-secondary-subtle: #E0F2FE;

  /* Accent */
  --color-accent: #E11D48;
  --color-accent-subtle: #FFE4E6;

  /* Neutrals & Surfaces */
  --color-bg-canvas: #F8FAFC;
  --color-bg-surface: #FFFFFF;
  --color-border: #E2E8F0;
  --color-border-hover: #CBD5E1;

  /* Typography */
  --color-text-main: #0F172A;
  --color-text-muted: #64748B;
  --color-text-inverse: #FFFFFF;
}
```

#### Use Case Description
* **Primary (`#4F46E5`):** Main interactive CTAs, active tab indicators, and progress bars.
* **Secondary (`#0284C7`):** Supplementary actions, secondary tags, documentation links, and non-critical metrics.
* **Accent (`#E11D48`):** Unread notification badges, critical warning states, and high-conversion micro-interactions.
* **Neutrals:** `--color-bg-canvas` for the main app background; `--color-bg-surface` for sidebar panels and data cards to create crisp layering.

#### Mood / Psychology
* **Perception:** Trustworthy, crisp, forward-thinking, and reliable.
* **Best suited for:** Cloud dashboards, modern developer tools, AI workflows, and fintech applications.

### Palette 2: "Terracotta & Warm Stone"
*An organic, humanistic palette designed for lifestyle platforms, community apps, and modern editorial tools.*

#### Colors & Hex Codes
* **Primary Colors:**
  * Base: `#C2410C` (Burnt Terracotta)
  * Hover / Active: `#9A3412` (Deep Rust)
* **Secondary Colors:**
  * Base: `#2E5A44` (Forest Pine)
  * Subtle Tint: `#E8F0EB` (Soft Celadon)
* **Accent Colors:**
  * Base: `#B45309` (Amber Ochre)
* **Background / Neutral Colors:**
  * Canvas / Base BG: `#FAFAF9` (Warm Alabaster)
  * Surface / Secondary BG: `#F5F5F4` (Stone Surface)
  * Card / Elevated BG: `#FFFFFF` (Clean White)
  * Border / Dividers: `#E7E5E4` (Stone Gray)
  * Text Muted: `#78716C` (Warm Charcoal — 4.8:1 on `#FAFAF9`)
  * Text Body / Headings: `#1C1917` (Deep Espresso — 16.5:1 on `#FAFAF9`)

#### CSS Variables Code
```css
:root {
  /* Brand / Primary */
  --color-primary: #C2410C;
  --color-primary-hover: #9A3412;
  --color-primary-subtle: #FFEDD5;

  /* Secondary */
  --color-secondary: #2E5A44;
  --color-secondary-subtle: #E8F0EB;

  /* Accent */
  --color-accent: #B45309;
  --color-accent-subtle: #FEF3C7;

  /* Neutrals & Surfaces */
  --color-bg-canvas: #FAFAF9;
  --color-bg-surface: #F5F5F4;
  --color-bg-card: #FFFFFF;
  --color-border: #E7E5E4;
  --color-border-hover: #D6D3D1;

  /* Typography */
  --color-text-main: #1C1917;
  --color-text-muted: #78716C;
  --color-text-inverse: #FFFFFF;
}
```

#### Use Case Description
* **Primary (`#C2410C`):** Checkout triggers, hero actions, key toggles, and brand moments.
* **Secondary (`#2E5A44`):** Category tags, success indicators, filter badges, and tertiary navigation.
* **Accent (`#B45309`):** Special offers, rating stars, bookmark markers, and feature flags.
* **Neutrals:** Warm off-whites reduce eye strain during prolonged reading; white surfaces pop naturally against `--color-bg-canvas` with minimal drop shadow.

#### Mood / Psychology
* **Perception:** Earthy, premium, approachable, thoughtful, and authentic.
* **Best suited for:** E-commerce, collaborative writing tools, knowledge bases, wellness products, and lifestyle web apps.

### Palette 3: "Nordic Teal & Signal Orange"
*A high-clarity palette built for data visualization, analytic consoles, and healthcare/scientific software.*

#### Colors & Hex Codes
* **Primary Colors:**
  * Base: `#0F766E` (Deep Teal)
  * Hover / Active: `#115E59` (Nordic Spruce)
* **Secondary Colors:**
  * Base: `#475569` (Steel Slate)
  * Subtle Tint: `#CCFBF1` (Aqua Frost)
* **Accent Colors:**
  * Base: `#EA580C` (Signal Orange — 4.6:1 contrast against white)
* **Background / Neutral Colors:**
  * Canvas / Base BG: `#F8FAFC` (Cool Off-White)
  * Surface / Sidebar BG: `#FFFFFF` (Pure White)
  * Border / Dividers: `#E2E8F0` (Crisp Border)
  * Text Muted: `#64748B` (Cool Slate — 4.6:1 on white)
  * Text Body / Headings: `#0B132B` (Dark Obsidian — 18.8:1 on white)

#### CSS Variables Code
```css
:root {
  /* Brand / Primary */
  --color-primary: #0F766E;
  --color-primary-hover: #115E59;
  --color-primary-subtle: #CCFBF1;

  /* Secondary */
  --color-secondary: #475569;
  --color-secondary-subtle: #F1F5F9;

  /* Accent */
  --color-accent: #EA580C;
  --color-accent-subtle: #FFEDD5;

  /* Neutrals & Surfaces */
  --color-bg-canvas: #F8FAFC;
  --color-bg-surface: #FFFFFF;
  --color-border: #E2E8F0;
  --color-border-hover: #CBD5E1;

  /* Typography */
  --color-text-main: #0B132B;
  --color-text-muted: #64748B;
  --color-text-inverse: #FFFFFF;
}
```

#### Use Case Description
* **Primary (`#0F766E`):** Main control buttons, active navigation states, primary data lines, and chart anchors.
* **Secondary (`#475569`):** Inactive states, metadata tables, pagination controls, and tooltips.
* **Accent (`#EA580C`):** Data anomalies, warning indicators, critical primary alerts, and callout banners.
* **Neutrals:** Cool white canvas and dark obsidian typography maximize legibility in dense data grids and complex tables.

#### Mood / Psychology
* **Perception:** Precision, balance, calm focus, and clinical clarity.
* **Best suited for:** Health-tech platforms, financial charts, monitoring consoles, and business analytics apps.
